# Personal Bio Website

## Overview
This project is a single-page personal bio website built using only semantic HTML. No CSS styling was used because the focus was on understanding HTML structure and semantic elements.

## Features
- Header with navigation links
- About section
- Skills section using a list
- Projects section using a table
- Contact section with a form
- Profile image with alt text
- External link
- Semantic HTML tags

## Semantic Tags Used
- header
- nav
- main
- section
- article
- aside
- footer

## What I Learned
- How to structure a webpage using semantic HTML
- Creating navigation links using anchor tags
- Using lists, tables, and forms
- Importance of accessibility through alt text and labels
- Organizing content with semantic tags for better readability and SEO
